¿Qué es el objeto generado por XMLHttpRequest?
Es un objeto del navegador que permite hacer peticiones HTTP a un servidor
desde JavaScript sin recargar la página (la base de AJAX). Con él se
configura la petición, se envía y se recibe la respuesta (responseText,
status, etc.).

¿Qué hace el método open de xhr?
Prepara o configura la petición: recibe el método HTTP ("GET"), la URL a la
que se va a consultar (la API de fakestoreapi) y si será asíncrona (true).
Todavía no la envía; eso lo hace xhr.send().

¿Qué hace el método onload de xhr?
onload es la función que se ejecuta cuando la respuesta del servidor ya
llegó completa. Ahí se lee xhr.responseText, se convierte de texto a objeto
con JSON.parse y se guarda en data.json. Como la petición es asíncrona, el
resto del código no espera; esta función se llama después.

PASO 2
¿Qué significa => en el código?
Es la sintaxis de función flecha (arrow function), una forma corta de
escribir una función anónima. "element => { console.log(element); }" es
equivalente a "function(element) { console.log(element); }". forEach la
ejecuta una vez por cada elemento del arreglo, pasándole el elemento como
parámetro.

Después se creó la función genTr(json), que crea un <tr> con cinco <td>
(id, title, price, description y category) y lo regresa; dentro del forEach
se agrega cada fila al tbody para llenar la tabla.

¿Qué hace filter y cómo funciona includes en este contexto?
filter recorre el arreglo y crea un arreglo NUEVO solo con los elementos
para los que la función regresa true; el arreglo original no cambia.
includes es un método de las cadenas que regresa true si el texto contiene
la subcadena indicada. Aquí, para cada producto se revisa si su title
contiene lo que el usuario escribió en el campo de búsqueda
(e.title.includes(input.value)); si sí, el producto se queda en el arreglo
filtrado. Distingue mayúsculas y minúsculas, y con el campo vacío regresa
todos los productos.
